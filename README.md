# MANDO SCRAP CARS

Offline 3D car scrapyard and restoration simulator for Android.

## Features
- Explore a 3D city.
- Buy scrap cars.
- Tow cars to your workshop.
- Repair engines and replace parts.
- Customize paint, wheels, and suspension.
- Sell restored cars for profit.
- Save progress and play offline.

## Engine
Godot 4
